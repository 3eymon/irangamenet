
# Iran Game Net 🎮

A gaming platform for discovering games and reading gaming news.

## Features
- Browse and explore games
- Read gaming news
- Search and filter games
- User authentication
- Responsive design

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Supabase
- TanStack Query
- Material UI
